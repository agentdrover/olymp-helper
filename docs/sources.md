## Формат заданий по рекомендациям (для генерации, G2)

Своими словами, без цитат:

- Часть 1 - вопрос с одним верным ответом из примерно четырёх.
- Часть 2 - вопрос с выбором нескольких ответов: верных от 0 до 5.
- Часть 3 - установить порядок последовательности или соответствие между двумя наборами.
- Часть 4 (по желанию) - биологические задачи или утверждения «да/нет».
- Форма закрытая, ответ однозначный; неверные варианты - только реальные биологические термины.
- Каждый класс охватывает и блоки более ранних классов; задания должны быть оригинальными.
