# Матрица покрытия SPEC-1.0

Требование SPEC → задача OH-T → AC → вид свидетельства.
Виды свидетельства: **тест** (автотест в CI, `test_ref` в AC), **CI** (шаг CI, `log_check`), **протокол** (ручная проверка или `ui_check`, протокол в сдаче).

Задачи: T01 #2011, T02 #2012, T03 #2013, T04 #2014, T05 #2016, T06 #2017, T07 #2018, T08 #2019, T09 #2015, T10 #2020.
Номера AC взяты из карточек хаба на 22.10.2026; при их изменении матрицу обновляет та же задача.

Для T01 (эта задача) сам SPEC проверяется ревьюером (T01 AC-1, протокол); CI этого коммита ничего не проверяет.

## Пробелы (требование без AC на 22.10)
Обнаружены при сборке матрицы. T01 AC в чужие карточки не добавляет; ниже предложение закрытия каждого пробела (карточка, AC в форме given/when/then, свидетельство).
1. §1.1: подписи на рисунке мельче читаемого размера — `unsupported`.
   Закрытие: T05, новый AC. Given: фикстура с рисунком, подписи которого при показе (560 px) мельче читаемого размера; when: родитель подтверждает рисунок; then: задание `unsupported`, ребёнку не показано. Свидетельство: тест `tests/test_figures.py`.
2. §1.3а: вход родителя сразу после 4-й цифры, ввод цифр с клавиатуры.
   Закрытие: T08, новый AC. Given: экран входа; when: вводятся 4 цифры клавишами без нажатия «Войти»; then: вход выполнен сразу после 4-й цифры, пятая цифра не нужна. Свидетельство: протокол (`ui_check`).
3. §1.2: поле `uncertainty` (low|high).
   Закрытие: T06, новый AC. Given: ответ модели с `uncertainty=high`; when: он разбирается и сохраняется; then: значение сохранено, структурно неверное значение отклонено как ошибка модели. Свидетельство: тест `tests/test_tutor_state.py`.
4. §1.7: вытеснение кэша страниц при лимите 500 МБ.
   Закрытие: T05, новый AC. Given: кэш рендера заполнен до лимита; when: рендерится новая страница; then: размер кэша не больше 500 МБ, вытеснена самая старая страница. Свидетельство: тест `tests/test_figures.py`.
5. §1.6: итоги хранятся бессрочно — очистка по сроку не должна их трогать (T08 AC-4 проверяет итоги только после ручного удаления).
   Закрытие: T08, новый AC. Given: занятие со сводкой старше 180 дней и сообщениями; when: запускается очистка; then: сообщения удалены, сводка на месте. Свидетельство: тест `tests/test_privacy.py`.
6. §1.1/§1.3: режим «только проверка по ключу» — состояние `answer_shown` и его вид в итоге занятия (уточнение по ревью #2011).
   Закрытие: T10, новый AC. Given: занятие, где ответ показан кнопкой «Показать ответ» после 2 попыток; when: родитель открывает итог; then: «ответ показан после 2 попыток, не разобрано», не «верно». Свидетельство: тест `tests/test_summary.py`.
