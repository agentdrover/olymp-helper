# Дизайн интерфейса

Макет интерфейса: https://claude.ai/artifact/DdayMFYeQHsPnFqgKYJcFZ

Макет — справка; нормативный текст — `docs/spec/SPEC-1.0.md` (§1.3а). При расхождении верен SPEC.

## Экраны и состояния (SPEC 1.3а)

Экраны
- Экран задания с панелью помощника (чат, голос, «помоги задать вопрос»); отдельного пункта «Спросить» в навигации нет.
- «Мои итоги» ребёнка: список занятий, журнал, ссылка «Как это работает».
- Лента проверки заданий родителем: исходная страница слева, карточка справа, счётчик «N из M».
- Вход родителя (PIN).
- Настройки (в том числе счётчик дней до этапа, по умолчанию выключен).

Карточки ленты проверки: «верно, ответ X — подтвердить и дальше»; «ключа нет»; «расхождение»; «нужен рисунок»; «открытый — исключить»; «спорный ключ от ребёнка».

Состояния панели помощника
- «думаю… обычно 5–15 с» (кнопки заблокированы);
- «основной канал не ответил, пробую второй»;
- «помощник сейчас не отвечает — проверка по ключу работает»;
- «на сегодня вопросы кончились — проверка по ключу работает».

Состояния голоса: нет доступа к микрофону; страница открыта не по HTTPS; «распознаю…»; запись длиннее 30 с; распознанный текст можно поправить перед отправкой.

Состояния входа родителя: «неверный PIN, осталось N попыток»; «вход закрыт до ЧЧ:ММ».

Подтверждения: открытие переписки родителем («Запись появится в журнале ребёнка»); удаление переписки (по занятию и целиком, со счётом сообщений); открытие решения по подсказке 3 («Открыть решение? Задание засчитается как разобранное по подсказке»).

Клавиши ленты: Enter — «верно и подтвердить», → — пропустить, E — поправить.
