# ADR 0001. Архитектура v1

Статус: принято (22.10.2026). Нормативный контракт — `docs/spec/SPEC-1.0.md`; здесь только решения и ссылки на разделы.

## Решения

1. **Приложение: FastAPI + Jinja + HTMX, SQLite в режиме WAL.** Данные и файлы — на томе `/srv/olymp` (SPEC 1.7). Python 3.12.
2. **Два контейнера.** Контейнер приложения и отдельный контейнер-исполнитель модели. CLI моделей запускаются только в исполнителе: без тома с данными, с файловой системой только для чтения, пустым рабочим каталогом, минимальным окружением и исходящими соединениями только к API своего провайдера. Приложение вызывает его по локальному сокету/HTTP (SPEC 1.4). (уточнение по ревью #2013) контейнер-исполнитель свой на каждый канал и держит только его токен; сервер и CLI работают под разными UID; рабочая область CLI — ограниченный tmpfs, очищаемый после каждого запроса; остаточный риск cursor-agent (shell в режиме ask) принят изоляцией и проверяется в OH-T09.
3. **Два канала модели.** Claude CLI (подписка) и cursor-agent (ключ Cursor), общий интерфейс `ModelChannel`, основной канал выбирается в настройках, при ошибке — одна попытка на запасном; дневной лимит запусков с учётом до запуска (SPEC 1.4).
4. **Доступ: домашняя сеть и HTTPS.** Сервис работает на K8 в LAN. Голос требует secure context, поэтому HTTPS: свой корневой сертификат, сертификат сервера с SAN на адрес K8, доверие на ноутбуке ребёнка (SPEC 1.7).
5. **Распознавание речи — локально.** MediaRecorder → ffmpeg → whisper.cpp в образе приложения, без загрузок во время работы; аудио удаляется после распознавания; голос наружу не уходит (SPEC 1.6, 1.7).
6. **Поиск по учебникам — SQLite FTS5** с одинаковой нормализацией для индекса и запроса (SPEC 1.7). Рендер страниц — локально (PyMuPDF).
7. **Секреты** (`CLAUDE_CODE_OAUTH_TOKEN`, `CURSOR_API_KEY`) не попадают в репозиторий, образ, логи и отчёты; доставляются при запуске на K8 задачей проекта home-infra.

## Последствия

- Модель не видит данных ребёнка за пределами переданного запроса; даже вызов инструмента моделью ничего не раскрывает.
- Установка на K8, сеть и секреты вне этого репозитория: задача в проекте home-infra.
- Один процесс приложения и SQLite достаточны для одного ребёнка и одного родителя; масштабирование вне v1.
